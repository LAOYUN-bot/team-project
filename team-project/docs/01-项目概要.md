## 一、项目简介

| 项 | 内容 |
|---|---|
| 项目名称 | **A02 面向未来工作的 AI 职业导航与终身学习伙伴系统** |
| 选题来源 | 课程团队项目选题（选题理念源自 2026「数字马力杯」A02；**按 v2.0 要求独立实现，不依赖任何指定商业平台**） |
| 一句话定位 | 让 AI 从「效率工具」升级为陪伴个体成长的「**认知伙伴**」 |
| 服务对象 | 高校学生、职场新人、转岗人群 |
| 核心场景 | 建档测评 → 生成 3–5 年路径 → 周学习单元 → 职场场景模拟训练 → 画像动态迭代 |
| 课程映射 | 《团队规范项目实训》第三部分团队项目实训（第 7–16 周） |

### 1.1 要解决的三个真问题（来自赛题难题）

| 难题 | 我们的回答 | 可验证的物证 |
|---|---|---|
| **P1 动态职业画像构建难** | 能力雷达**版本化 + 快照不可变**，分值由**可审计公式**算出而非模型编造 | 完成一次训练后画像从 v3 → v4，两版本可逐维对比（`competency_radar.calc_input_json` 留存完整计算输入） |
| **P2 学习路径空泛** | 强制输出粒度到「周」，**每个单元必须有可验证产出物与工时**，否则业务规则校验打回 | `SchemaValidator.validateBusinessRules`：阶段数 <4 或阶段缺产出物 → 校验失败 |
| **P3 人机信任与长期陪伴** | 固定人设「灯塔」+ 结构化上下文注入 + 连击打卡 + 里程碑 + 情绪感知回应 | 激励文案中的事实（打卡天数/完成任务数）**全部来自数据库**，不是空洞鼓励 |

### 1.2 差异化设计（答辩要点）

1. **AI 的输出永远不直接写业务真相源**——必须先过 Schema 校验与业务规则二次校验，
   落库发生在业务模块内。这不是流程要求，是代码结构保证的。
2. **失败时怎么办，比顺利时能跑更重要**——结构化输出契约（抽取 → 修复 → 校验 → 重试 → 兜底）
   与 AI 通道自动降级，演示现场可主动触发（「制造一次校验失败」按钮）。
3. **分值算得出来，也解释得清**——雷达 8 维的来源、权重、衰减因子全部可见、可复算、可配置。

## 二、技术栈（★ 标记为本团队使用的**新技术**）

| 层次 | 技术 | 版本 | 是否新技术 | 用途 |
|---|---|---|---|---|
| 语言 | Java | 17 | | 后端主语言（课程实验一要求） |
| 后端框架 | **Spring Boot** | 4.0.8 | ★ | Web 容器、依赖注入、自动配置 |

| 持久层 | Spring JdbcTemplate | 7.0.9 | | 跨表聚合与分析型查询（差距、匹配度、画像统计） |
| 数据库 | H2 内存库（默认）/ MySQL 8（可选） | 2.2.224 / 8.0 | ★ | 业务真相源；零配置演示 |
| 认证授权 | 自实现 HS256 JWT + **BCrypt** | — | ★ | 登录、RBAC、HttpOnly Cookie 下发 |
| 参数校验 | 手写校验 + 统一错误码 | — | | 防注入第一道闸 |
| 前端 | 原生 ES6 + **手写 SVG 图表库** | — | ★ | 雷达图 / 进度环 / 成长曲线 / 热力图 |
| 前端 | Vue 3 + Vite（**计划中**，见 §五） | — | ★ | 课程实验二要求；当前环境无 npm 源 |
| 流式传输 | **SSE**（`SseEmitter` + `fetch` 流式解析） | — | ★ | 路径生成、AI 对话逐字返回 |
| AI 能力 | **统一模型网关**（`LlmGateway` + OpenAI 兼容适配器 + 模型分层路由） | — | ★ | 6 类 AI 场景，改配置即可切换 DeepSeek/通义/智谱/Ollama |
| RAG | **自建管线**（语义切块 + TF-IDF 向量 + 检索 + 双判据拒答） | — | ★ | 带来源回答，52 条评测集 |
| 成本与限流 | **令牌桶 + 二级缓存 + 调用记账** | — | ★ | NFR-8：限流时降级不报错 |
| AI 协议 | **MCP（Model Context Protocol）** | 2024-11-05 | ★ | 3 个只读工具，纯标准库实现 |
| 安全 | AES-GCM 字段加密 + 传模型前脱敏管道 | — | ★ | 隐私保护（NFR-3） |
| 构建 | Maven | 3.9 | | 依赖管理与编译 |
| 版本控制 | Git + GitHub Actions | — | ★ | 分支模型、PR 评审、CI |
| 测试 | JUnit 5 + 自研零依赖自检脚本 | 6.0.3 | ★ | 980 项检查 |

> **新技术说明**：★ 共 12 项，覆盖赛题与课程都强调的方向（AI 平台、MCP、流式、
> 版本化算法、隐私工程、CI）。其中 MyBatis、SSE、JWT/RBAC 直接对应课程五个实验。
