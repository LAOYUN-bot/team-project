# 07 原型演示视频脚本（3–5 分钟）

> 课程交付物③：**原型演示视频 3–5 分钟，覆盖核心流程，含 AI 功能实拍**。
> 本文档是**分镜脚本**，照此录制即可；录制时把「旁白」念出来，屏幕按「画面」操作。
>
> **界面说明**：产品名「灯塔」，8 个页面——今日 / 我的能力 / 职业路径 / 学习计划 /
> 情景练习 / 职业伙伴 / 资料问答 / 设置。界面上**不出现任何开发说明文字**，
> 所以旁白里要主动把「这背后是什么技术」讲出来，否则老师看不到工作量。

---

## 一、录制前准备（务必先做）

```powershell
cd team-project
.\run.ps1
# 等控制台出现 "Started A02Application"，再等 10 秒让演示数据播种完成
```

| 检查项 | 做法 | 期望 |
|---|---|---|
| 浏览器窗口干净 | 用无痕窗口，只开一个标签页 | 地址栏无杂乱历史 |
| 缩放 | 浏览器缩放 100%，窗口 1600×900 以上 | 文字清晰 |
| 语言 | 输入法切英文，避免弹候选框 | —— |
| 数据 | 登录 `demo / demo1234` | 「今日」页有连续天数与进度环，「我的能力」有多次评估 |
| 预热 | 提前把每个页面点一遍 | 图表与数据已缓存，录制时无卡顿 |
| 录制工具 | OBS / 系统录屏 / PPT 录屏均可 | 输出 1080p |

> **时间控制**：总时长卡在 **3 分 40 秒 – 4 分 30 秒**之间。
> 低于 3 分钟会被判「覆盖不全」，超过 5 分钟会被扣「结构不精炼」。

### 第 7 镜的预置台词（提前放到剪贴板，录制时 Ctrl+V）

```
林工你好，先说背景：需求方希望本迭代加一个导出功能，我确认过是面向运营的月报场景。我理解你们排期也紧，所以我先做了影响分析——涉及 2 个接口和 1 张表，预计 3 人天。
```

```
我准备了两个方案：方案一是本迭代做简化版导出，1 人天，先满足月报；方案二是完整版放到下个迭代，3 人天。我倾向方案一，风险可控。你觉得哪个更合适？
```

```
如果走方案一，前端和测试的工作我可以接过来，你只需要确认表结构调整会不会影响现有查询。截止时间建议定在本周五，这样下周一就能联调。
```

> 这三段台词含有**结构化表达、业务数据、主动推进动作**，能让评分明显高于随口回答，
> 演示效果更直观（避免出现「评分很低」的尴尬画面）。

## 四、录制注意事项

| 事项 | 说明 |
|---|---|
| **不要录制加载等待** | 若某页加载超过 2 秒，剪辑时加速或剪掉 |
| **鼠标要「指」不要「晃」** | 讲到哪个图就把鼠标停在那个图上 |
| **旁白不要念代码** | 讲「做了什么、为什么这么做」，不讲实现细节 |
| **一镜到底还是分段** | 建议分段录（每镜一段），后期拼接，避免一处口误全片重录 |
| **字幕** | 至少给关键结论加字幕（动态画像、987 项检查、防幻觉） |
| **音频** | 用耳麦而不是笔记本内置麦；音量标准化（-16 LUFS 左右） |
