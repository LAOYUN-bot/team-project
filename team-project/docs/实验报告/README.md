# 实验报告目录说明

> 课程要求：**每人提交 5 份实验报告**，报告含主要步骤截图与关键代码说明，
> 末尾含总结与反思 + 「AI 工具使用记录」。

---

## 一、提交要求（摘自课程方案）

| # | 要求 | 说明 |
|---|---|---|
| 1 | 每个实验独立（或结对）完成，提交一份实验报告 | 5 份 |
| 2 | 报告含**主要步骤截图与关键代码说明** | 截图需是自己机器上的运行结果 |
| 3 | 报告末尾含**总结与反思** | 写自己学到了什么、哪里卡住 |
| 4 | 报告末尾含 **AI 工具使用记录** | 用了哪些 AI 工具、在哪些环节、提示词要点、**产出如何验证** |
| 5 | 严禁直接提交 AI 生成的未理解代码 | 教师随机抽测代码讲解 |

## 三、报告撰写方式

本目录下 5 份文件是**带本项目真实代码与命令的模板**：

- ✅ **可直接沿用**：实验目标、步骤命令、关键代码位置与说明、可复现的验证方式；
- ✏️ **需要各自填写**：姓名学号、**自己机器上的运行截图**、自己的总结反思、
  自己真实的 AI 使用记录与验证过程。

> 抄模板里的「总结与反思」没有意义 —— 课程抽测会问代码细节，
> 而且 AI 使用记录的核心是「**你是如何验证 AI 产出的**」，
> 这部分每个同学遇到的坑不一样，照抄反而会在答辩时露馅。

---

## 四、每份报告的通用骨架

```
一、实验目标（课程原文）
二、实验环境（JDK / Maven / IDE / 数据库 版本）
三、实验步骤
    3.1 …（步骤 + 截图 + 关键代码说明）
四、遇到的问题与解决
五、验证与结果（命令 + 输出）
六、总结与反思
七、AI 工具使用记录
    7.1 使用的工具与环节
    7.2 提示词要点
    7.3 产出如何验证（必须有具体手段）
    7.4 AI 出的问题与我的处理
```

## 五、快速开始（五份报告都能用到的环境准备）

```powershell
# 1) 环境自检
java -version          # 需 JDK 17
mvn -v                 # 需 Maven 3.9+
node -v                # 自检脚本需要

# 2) 启动项目
cd team-project
.\run.ps1              # → http://localhost:8080

# 3) 演示账号
#    demo / demo1234（普通用户，已预置完整闭环数据）
#    admin / admin1234（管理员，用于 RBAC 演示）
```
