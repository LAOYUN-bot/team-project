## 二、本团队自行实现的部分（无第三方许可约束）

以下组件为**本项目自行编写**，不引入外部二进制依赖，其著作权归团队：

| 组件 | 位置 | 说明 | 为何自己写 |
|---|---|---|---|
| SVG 图表库 | `static/js/charts.js` | 雷达图 / 进度环 / 成长曲线 / 热力图 / 条形图 | 开发机离线，npm 源不可达，无法安装 ECharts；自绘后**零前端依赖**，反而更适合离线演示 |
| MCP Server | `mcp-server/server.py` | MCP 协议（stdio + HTTP）、3 个只读工具 | 无外网无法 `pip install mcp`；仅用 Python 标准库实现，协议行为一致 |
| JWT 实现 | `platform/security/JwtService.java` | HS256 签发与校验 | 离线仓库无 jjwt；用 JDK 原生 `HmacSHA256` 实现标准 JWT |
| RBAC 拦截器 | `platform/security/AuthInterceptor.java` | `@RequireRole` 注解鉴权 | 离线仓库无 `spring-security-web` |
| 结构化输出契约 | `ai/schema/*`、`ai/adapter/AbstractStructuredAiAdapter` | JSON 抽取 / 修复 / 校验 / 重试 / 兜底 | 这是本项目的**核心工程价值**，本就应自研 |
| 零依赖自检脚本 | `tools/*.mjs` | 接口契约、图表断言、MCP 契约 | 无 npm 依赖，Node 内置能力即可 |

## 三、AI 生成内容的许可与标注

| 项 | 说明 |
|---|---|
| **代码** | 本项目部分代码由 AI 辅助生成后经人工理解、修改与验证。AI 工具（Claude Code / Cursor 等）的产出**不主张独立著作权**，团队已对其充分修改并承担最终责任。 |
| **标注方式** | 对 AI 参与度高的片段使用 `// AI-assisted` 注释；详见 `docs/AI使用记录.md` |
| **文案** | 提示词与文档中的示例文案由团队撰写或改写，未直接引用受版权保护的第三方文本 |
| **数据** | 知识图谱中的岗位 / 技能 / 课程 / 认证数据来自**公开招聘信息的脱敏聚合与自构造模拟数据**，不含真实个人数据；知识库条目均为政策与行业公开资料的改写摘要 |
| **图片素材** | 项目界面未使用第三方图片素材（图表全部为代码绘制 SVG） |
| **演示视频配乐** | 若使用背景音乐，必须选用免版税/可商用素材并注明来源（见 `docs/07-演示视频脚本.md` §六） |

## 四、合规自查结论

| 检查项 | 结论 |
|---|---|
| 是否使用了 GPL/AGPL 等强传染性许可的库？ | 否。运行时尚无 GPL 组件；Logback 为 EPL/LGPL 双许可，且以**未修改的库形式**依赖，不触发传染 |
| 是否包含需要商业授权的组件？ | 否。全部为 Apache-2.0 / MIT / EPL / MPL 等宽松许可 |
| 是否保留了必要的版权声明？ | 是。二进制依赖未修改，其 `LICENSE` / `NOTICE` 随 jar 分发 |
| 是否使用了爬取或侵权数据？ | 否。仅公开资料改写与自构造模拟数据 |
| 是否上传了真实个人信息到公网模型？ | 否。传模型前经 `PiiRedactor` 脱敏；运行默认使用本地 Mock 通道 |
| AI 生成内容是否有标注？ | 是。代码 `// AI-assisted`；界面统一「AI 生成」标识；文档见 `docs/AI使用记录.md` |
| 是否在文档中说明了 AI 能力边界？ | 是。`persona.txt` 写明边界；界面下发 `disclaimer`；`docs/AI使用公约.md` §七 |
