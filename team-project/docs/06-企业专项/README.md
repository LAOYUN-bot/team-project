## 关于本目录的诚信说明

`①` 与 `④` 中涉及平台的部分**未完成即标注未完成**，不放置任何伪造截图或占位图。
原因：这两项依赖蚂蚁百宝箱企业版的账号、网络与渠道发布权限，
而当前开发环境完全离线且无企业版权限（需求文档风险 R-1）。

我们在架构上已经为这种情况做了准备——`AiChatPort` 端口 + Mock 适配器 + 一键切换，
使得**平台权限未到不阻塞任何其他关键路径**，同时保留了拿到权限后半天内补齐的能力。
