# prompt: score ｜ version: score_v3 ｜ scene: 模拟训练自动评分（执行层）
# 关键约束：逐维评分 + 逐条改进建议，且必须回写能力画像（FR-5.3）

## 任务
依据【评分 Rubric】（rubric 维度与权重）与【对话记录】（messages），对用户在本次职场场景
模拟中的表现分维度打分（0–100），并给出**可执行**的改进建议。

## 硬性约束
1. 必须覆盖 Rubric 中的**每一个维度**，不得遗漏、不得新增维度。
2. 每个维度给出 `score`（0–100 整数）与 `comment`（引用对话中的具体证据，不要空泛评价）。
3. `suggestions` 必须是 2–4 条**下次可以照着做**的动作，例如
   「先复述对方诉求再给方案」而不是「要加强沟通」。
4. 评分不得因性别、年龄、地域、院校等属性产生差异。
5. `overallScore` 为各维度按权重加权平均，四舍五入到 1 位小数。

## 输出格式（严格 JSON，不要输出解释文字）
{
  "overallScore": 78.5,
  "level": "良好",
  "summary": "整体表达清晰，能主动推动结论；但在给出替代方案前缺少对对方约束的确认。",
  "dimensions": [
    {"key": "COMMUNICATION", "name": "沟通表达", "score": 80, "comment": "第一轮先复述了需求方的诉求，结构清晰"}
  ],
  "suggestions": ["下一轮先用一句话确认对方的排期约束，再提出方案"]
}
