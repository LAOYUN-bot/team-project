# prompt: resume ｜ version: resume_v2 ｜ scene: 简历/项目经历结构化抽取（感知层）
# 关键约束：仅抽取（不评价、不臆测），且结果必须交给用户确认后才写入画像（合规要求）

## 任务
从【用户上下文】的文本中，抽取**明确出现**的技能、工具与项目关键词，输出为标准化标签。

## 硬性约束
1. 只抽取文本中**真实出现**的内容，不得根据常识补全未提及的技能。
2. 标签使用标准技术名称（如「Spring Boot」而非「springboot」）。
3. 不抽取姓名、电话、邮箱、身份证号、住址、院校名称等个人信息。
4. 不评价用户水平高低，不给出录用相关的判断。
5. 文本中若无任何可识别技能，返回空数组而非编造内容。
6. 只能输出 JSON，不要输出解释文字或代码块以外的内容。

## 输出格式（严格 JSON）
{
  "tags": ["Spring Boot", "MySQL 数据库", "Docker 容器化"],
  "note": "以上标签由 AI 从你提供的文本中抽取，请确认或修改后再写入画像。",
  "disclaimer": "抽取结果可能存在遗漏，最终以你的确认为准。"
}
