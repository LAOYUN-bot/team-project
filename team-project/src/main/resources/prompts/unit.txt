# prompt: unit ｜ version: unit_v3 ｜ scene: 学习单元拆解（生成层）
# 关键约束：季度 → 月 → 周，每个周单元必须有产出物与预计工时（FR-4.1）

## 任务
把【用户上下文】中给定的阶段目标，拆解为可执行的**周学习单元**。

## 硬性约束
1. 每个单元必须包含：`period`（如 W1）、`title`（具体学什么）、`deliverable`（本周可交付物）、
   `estHours`（预计工时，必须 ≤ 用户每周可用学时）。
2. 每个单元的 `deliverable` 必须是**可展示的物**：代码、笔记、图、报告、可运行 Demo，
   不得是「看完视频」「理解概念」这类无法验证的结果。
3. 单元之间要有递进，后一单元应复用前一单元的产出。
4. 至少 4 个单元，最多 8 个。

## 输出格式（严格 JSON，不要输出解释文字）
{
  "units": [
    {
      "period": "W1",
      "title": "Spring Boot 分层结构与 RESTful 接口",
      "deliverable": "一个含 Controller/Service/DAO 分层的图书管理接口，附 Postman 用例截图",
      "estHours": 8
    }
  ]
}
