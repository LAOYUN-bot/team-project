# Java 后端开发工程师岗位能力要求（公开招聘信息脱敏聚合）

## 一、岗位职责

负责后端服务的设计、开发与维护；参与需求评审与技术方案设计；保障接口的稳定性与性能；配合前端完成联调；参与线上问题排查与优化。

## 二、硬性技能要求

第一，Java 语言基础扎实，理解面向对象设计、集合、泛型、异常处理与多线程基础。第二，熟练使用 Spring Framework 与 Spring Boot，理解依赖注入、AOP、事务传播机制。

第三，熟悉关系型数据库 MySQL，能够编写复杂 SQL、看懂执行计划、进行索引优化。第四，熟悉 Redis 等缓存中间件，理解缓存穿透、缓存雪崩与一致性问题的处理方式。

第五，熟悉 RESTful 接口设计规范，能编写接口文档。第六，掌握 Git 版本控制与 Maven 构建，具备基本的 Linux 命令能力。

## 三、工程能力要求

要求具备单元测试习惯，能为核心逻辑编写测试；了解容器化部署（Docker）与基础 CI/CD 流程；具备日志排查与链路追踪的实践经验。

对中级岗位，通常还要求有微服务架构经验，理解服务拆分边界、分布式事务与限流降级方案。

## 四、软性要求

沟通表达清晰，能与产品、测试、前端有效协作；具备问题拆解能力，遇到陌生问题能定位到可验证的小问题；有持续学习习惯。

## 五、面试常见考察点

集合与并发原理、JVM 内存模型与垃圾回收、Spring 事务失效场景、MySQL 索引与锁、缓存一致性方案、接口幂等设计、线上问题排查思路。
