# AI 应用开发工程师岗位能力要求（公开招聘信息脱敏聚合）

## 一、岗位职责

负责大模型应用的设计与开发；搭建 RAG 检索增强生成管线；设计提示词与评测方案；负责智能体与工具调用编排；保障线上服务的稳定性与成本可控。

## 二、硬性技能要求

第一，具备扎实的编程能力（Python 或 Java），能独立完成服务开发。第二，理解大语言模型的工作原理与能力边界，包括上下文长度、幻觉产生机制、温度参数对输出的影响。

第三，掌握提示工程：能编写分层的 System / Context / Task / Format / Guard 提示结构，并做版本化管理。第四，掌握 RAG 的核心环节：文档切块策略、向量化、相似度检索、重排与上下文拼装。

第五，了解向量数据库的使用（如 Milvus、Redis Stack 或 FAISS），理解召回率与准确率的权衡。

## 三、工程能力要求

要求能把模型调用封装为统一网关，支持多模型切换与降级；具备限流、缓存、退避重试与熔断的工程意识；能对模型输出做结构化校验（JSON Schema）并设计兜底策略。

要求具备成本意识：能估算 token 消耗、设计缓存策略、避免调试循环造成的费用失控。

## 四、AI 安全与伦理要求

要求理解提示注入的风险与防护（输入校验、System 层防护、工具只读）；理解数据脱敏要求，敏感信息不得上传第三方模型；能对模型输出做人工复核与责任归属界定。

## 五、常见考察点

如何降低幻觉、如何评估 RAG 效果（Recall@K 与答案准确率）、如何处理模型限流、如何做到换模型不改业务代码。
