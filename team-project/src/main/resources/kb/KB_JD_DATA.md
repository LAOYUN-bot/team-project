# 数据分析师岗位能力要求（公开招聘信息脱敏聚合）

## 一、岗位职责

负责业务数据的采集、清洗与分析；搭建与维护核心指标体系；输出分析报告并给出可执行的业务建议；支持 A/B 实验设计与效果评估。

## 二、硬性技能要求

第一，熟练掌握 SQL，能独立完成多表关联、窗口函数与复杂聚合。第二，熟练使用 Python 进行数据处理，掌握 Pandas 与 NumPy 的常用操作。

第三，掌握统计学基础，理解假设检验、置信区间与常见分布；能正确解读显著性，避免把相关性当作因果性。

第四，熟悉数据可视化工具（如 Tableau、Power BI 或代码绘图），能把分析结论表达清楚。

## 三、业务能力要求

要求理解业务指标之间的关系，能设计指标体系（北极星指标、过程指标、护栏指标）；熟悉漏斗分析、留存分析、用户分群等常见分析方法。

对中高级岗位，要求具备数据仓库建模基础（维度建模、宽表设计），了解 Hive 或 Spark 的基本使用。

## 四、软性要求

较强的业务理解力与沟通能力，能把数据结论翻译成业务动作；具备批判性思维，能质疑数据口径与异常值来源。

## 五、常见误区

只做取数不做分析、只堆图表不给结论、忽略数据口径变化导致的结论漂移，是新人分析师最常见的三个问题。
